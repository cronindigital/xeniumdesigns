FAQ

Common questions

How long does it take to build a dashboard?

Most dashboards are delivered within 1 to 2 weeks, depending on the number of data sources and complexity. We will give you a timeline with your quote.

Do I need to host anything?

No. Your dashboard is a self-contained HTML file. We can host it for you, or you can put it on any static file host, your own server, or even open it locally.

Will it work on my phone?

Yes. Every dashboard we build is fully responsive. It looks great on desktop, tablet, and mobile.

What if my data source is not listed?

We can connect to almost anything with an API or a spreadsheet export. Get in touch and we will figure it out.

Is there a monthly fee?

Our standard pricing is a one-off build fee. If you want ongoing maintenance, updates, or new features, we offer monthly retainers too. Totally optional.

Can I see a demo first?

Absolutely. We can build a quick proof of concept using sample data so you can see exactly what you are getting before committing.
