API key guides, step by step

Plain-English walkthroughs for getting the API keys your dashboard needs. Written for people who have never fetched one before.

Every dashboard we build pulls data straight from the tools your business already uses: your website analytics, your course platform, your email marketing, your social channels. To make that connection, each tool needs an "API key", a long random password-like string that lets our dashboard fetch your numbers automatically.

If you have never fetched an API key before, that sentence might as well be a different language. That is exactly why these guides exist. Each one takes a single service and walks you, click by click, through getting its key. No jargon, no assumed knowledge, and every guide checked against the official documentation for the current version of the service.

Send us the key through the usual secure channel once you have it, and that service is connected for good.
